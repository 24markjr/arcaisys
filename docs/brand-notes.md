# Brand notes (Phase 0 analysis)

## Arcaisys mark

An ascending, open "A" (amber → orange) with an "S" ribbon (red → deep red) sweeping up
through it, plus a free-floating chevron at the right. The wordmark is a squared geometric
sans in coral, letter-spaced wide.

Visual traits to carry into the website:

- **Ascent** — the dominant direction is lower-left to upper-right.
- **Ribbon** — the S is a flowing band that tapers at both ends; the basis for the site's
  signature line graphic.
- **Warm-to-deep gradient** — amber at the top/left, deep red at the bottom/right. Used only
  for brand graphics, never on body text or every button.
- **Faceted planes** — the A is built from flat angled planes with a soft shadow on the
  inner fold.

## Product family system

Hospio, Meridian and PACS share: navy wordmark in a heavy grotesque, one gradient accent
element in the symbol, and a tracked uppercase tagline of full-stop-separated verbs flanked
by rules. The website reuses that tagline pattern as a typographic device — it is already
part of the family's visual language.
